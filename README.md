# Co-working with AI: UMBC faculty workshop

[Open the workshop webpage](https://zzbatmos.github.io/ai-cowork-event-site/).

This public repository contains the workshop webpage, the organizer-approved promotion package, and two entirely fictional homework exercises. Download the repository with **Code > Download ZIP**, unzip it, and open `index.html` locally while keeping the accompanying folders in place.

- [Promotion package](demonstration1_write_recommendation_letter/): source documents, the demonstration prompt, and an AI-generated example letter for human review. The organizer confirmed that the package is based on public website materials and authorized its inclusion.
- [PHYS623 fictional homework](demonstration2_synthetic_homework/README.md): assignment, four synthetic submissions, rubric, and a separate instructor key.
- [Avengers 101 fictional homework](demonstration2_avengers101/README.md): a short assignment and four humorous submissions for testing reuse of the grading skill, plus a separate instructor key.

Keep instructor keys and generators out of the grading inputs. All submissions in the two exercise folders were newly composed; no real student homework, gradebooks, or identity keys are included. Promotion teaching evaluations belong to the organizer-approved promotion package and are distinct from the fictional homework exercises.

AI-generated letters, grades, scientific summaries, and illustrations are demonstration outputs requiring human review. Follow the webpage's event-use guidance. Public availability does not confer a new license to third-party articles or other source materials; their existing rights and terms remain applicable.

`PUBLIC_MANIFEST.json` lists published file hashes. This repository contains selected workshop artifacts and its own website history, not the private working repository's history.
