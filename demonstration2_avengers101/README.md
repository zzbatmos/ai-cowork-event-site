# Avengers 101: How to Defeat Dr. Doom

A short, entirely fictional Homework 2 for testing a reusable grading skill on a different course and assignment. No real student work was used. No Marvel canon expertise is required.

`Avengers101_Demo_Pack.zip` contains five one-page PDFs: the assignment (including the rubric) and submissions by Shuri, Peter Quill, Scott Lang, and Drax. Upload those five PDFs to a new Google Drive folder. Keep the `instructor/` folder and this README out of the grading inputs.

The constructed scores are 100, 75, 50, and 30 respectively. The separate instructor key explains the deductions. The assignment uses an explicit four-criteria-per-question rubric to make the expected totals easy to check. Each criterion is worth 5 points; humor and character reputation are not grading criteria.

After creating the reusable Google Drive Homework Grading skill, try:

> Use $google-drive-homework-grading for Avengers 101, Homework 2: How to Defeat Dr. Doom. The materials are in [paste the new Drive folder URL]. This is a fictional training exercise with no academic term. The assignment includes a rubric; I am not providing an answer key, so establish a reference approach from the scenario and rubric. Grade all four submissions, use anonymous labels in the report with a separate fictional-name mapping, and explain each deduction. Do not use online research or character reputation. Save a concise PDF report locally.

The new Drive folder has not been created or populated by this generator. The new grading skill must already have been created before using the invocation above.

Editable Markdown versions accompany the PDFs. Rebuild using `python build_samples.py` with ReportLab installed. The generator reads no outside materials and writes no student records.
